# План внедрения улучшений из Deck-Shelves в Projacktor

План адаптации архитектурных и оптимизационных решений из последних релизов [Deck-Shelves](https://github.com/santojon/Deck-Shelves) (v3.3.0 – v3.3.4, PR #126) для плагина Projacktor на Steam Deck.

---

## Цели и задачи
1. **Энергоэффективность:** Устранить повышенное потребление батареи и нагрузку на CPU в моменты простоя каталога (пауза тяжелых CSS-анимаций, фоновых баннеров и бесконечных шиммеров).
2. **Стабильность фокуса GamepadUI:** Предотвратить сброс или перехват фокуса нативными рефлексами SteamUI при возврате из плеера или деталей фильма в каталог.
3. **Реактивный режим ввода:** Динамически скрывать или показывать подсказки кнопок контроллера (`A`, `B`, `L1/R1`) в зависимости от текущего источника ввода (геймпад vs трекпад/мышь).
4. **Интеграция с системным скринсейвером SteamOS:** Корректно определять работу системного `ScreensaverPopup` и не нагружать систему в фоновом режиме.
5. **Оптимизация кэша постеров и медиа:** Исключить повторную загрузку неизменных CDN-изображений и оптимизировать отрисовку внеэкранных элементов.

## Этап 2. Стабильность фокуса GamepadUI (Focus Guard)

- [ ] **2.1. Модуль защиты фокуса `src/runtime/focusGuard.ts`**
  - **Детекция намеренного действия пользователя:** Подписка на нативное событие `vgp_ondirection`.
    - При любом физическом нажатии стрелки/стика пользователем — немедленная отмена (`abort()`) любых автоматических попыток восстановления фокуса.
  - **Защита от нативного рефлекса SteamUI:**
    - Steam Big Picture пытается сбросить фокус на первый элемент/поиск через 0.8–1.8 с после монтирования страницы.
    - Реализация мягкого подтверждения (до 3 попыток с интервалом ~200мс), гарантирующего сохранение фокуса на целевой карточке/вкладке без борьбы с пользователем.
- [ ] **2.2. Интеграция с существующей навигацией**
  - Подключение `focusGuard` в `src/hooks/useEnsureFocus.ts` и `src/hooks/useGridNavigation.ts`.
  - Сохранение активного элемента при переходе в плеер/детали фильма и надёжное восстановление при нажатии кнопки «Назад» (`B`).

## Этап 4. Интеграция с системным скринсейвером SteamOS

- [ ] **4.1. Доработка `src/runtime/screensaverInhibitor.ts`**
  - Добавить метод детекции системного скринсейвера SteamOS:
    ```ts
    export function isNativeScreensaverActive(): boolean {
      try {
        const ctrl = (globalThis as any).FocusNavController;
        const ctx = ctrl?.m_ActiveContext ?? ctrl?.m_LastActiveContext;
        const trees = ctx?.m_rgGamepadNavigationTrees ?? [];
        const popup = trees.find((t: any) => t?.m_ID === "ScreensaverPopup");
        return !!popup?.BIsActive?.();
      } catch { return false; }
    }
    ```
  - Если активен системный скринсейвер SteamOS (когда видео не воспроизводится), переводить Projacktor в режим глубокого сна (приостановка обновлений UI и сетевых опросов).
  - Снимать подавление спящего режима во всех случаях, кроме активного воспроизведения видео в плеере.
