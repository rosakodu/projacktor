# Projacktor

[🇷🇺 Русский](README.md) | [🇬🇧 English](README.en.md)

Плагин для Decky Loader на Steam Deck, превращающий консоль в полноценный медиацентр и онлайн-кинотеатр в стиле Steam Big Picture (Игровой режим). Каталог фильмов, сериалов, мультфильмов и аниме, поиск торрент-раздач через JacRed, фоновая загрузка через встроенный Aria2c, онлайн-просмотр и OLED-режим энергосбережения.

![Screenshot](assets/preview.png)

## 📋 Возможности

- **Нативный интерфейс Steam Big Picture**: Создан специально для SteamOS с идеальной адаптацией под экран и управление Steam Deck.
- **Один экран = один раздел**: Быстрая и плавная навигация между разделами («Сегодня смотрят», «Сегодня в тренде», «Высокий рейтинг») без визуальной перегрузки.
- **Богатый каталог контента**: Вкладки «Главная (Фильмы)», «Сериалы», «Мультфильмы», «Аниме» с подробной информацией (постеры, описания, рейтинги, даты выхода).
- **Поиск торрент-раздач (JacRed)**: Интегрированный поиск по проверенным торрент-трекерам с фильтрацией по качеству, размеру и сидам.
- **Встроенный менеджер загрузок (Aria2c)**: Высокоскоростное скачивание контента прямо во внутреннюю память консоли или на MicroSD карту.
- **Онлайн-просмотр и стриминг**: Возможность смотреть фильмы и отдельные серии сериалов онлайн без ожидания полной загрузки.
- **Встроенный плеер**: Полноэкранный плеер с поддержкой перемотки, паузы, выбора аудиодорожек и гибкого управления.
- **MagicBlack (OLED режим выключенного экрана)**: Скачивание фильмов и сериалов с функцией выключенного дисплея (кнопка с луной 🌙 в карточке раздачи и в библиотеке). Экран полностью заливается чёрным цветом (`#000000`), отключая пиксели OLED-экрана для экономии заряда и защиты от выгорания, а система защищена от засыпания. Пробуждение — по нажатию любой кнопки геймпада или касанию экрана.
- **Локальная библиотека**: Управление сохраненными загрузками, удаление и быстрый запуск просмотренных медиафайлов.

## 🎮 Управление (Геймпад Steam Deck)

Интерфейс оптимизирован для управления физическими кнопками геймпада Steam Deck:

- **L1 / R1**: Мгновенное переключение верхних вкладок по кругу (`Главная ⇄ Сериалы ⇄ Мультфильмы ⇄ Аниме ⇄ Поиск ⇄ Библиотека ⇄ Настройки ⇄ Главная`).
- **D-pad ↓ / ↑**: Вертикальное переключение между разделами каталога («Сегодня смотрят» ⇄ «Сегодня в тренде» ⇄ «Высокий рейтинг»).
- **D-pad ← / →**: Горизонтальное перемещение фокуса между карточками фильмов с автоматическим центрированием активного постера.
- **Кнопка A (OK)**: Открыть карточку фильма/сериала, список раздач и серий.
- **Кнопка B (Назад)**: Закрыть модальное окно / Назад.

## 📥 Установка

1. Скопируйте папку плагина в директорию плагинов Decky Loader:
   ```bash
   /home/deck/homebrew/plugins/Projacktor
   ```
2. Установите права на исполнение для встроенных утилит:
   ```bash
   chmod +x /home/deck/homebrew/plugins/Projacktor/bin/*
   ```
3. Перезапустите службу Decky Loader:
   ```bash
   sudo systemctl restart plugin_loader.service
   ```
