# Инструкции и правила проекта Projacktor

## Запуск и взаимодействие со Steam Deck

Для открытия плагина, переключения вкладок, перезагрузки и снятия скриншотов со Steam Deck **ВСЕГДА** используй готовый скрипт:

```bash
./open_projacktor.sh [IP] [опции]
```

### Основные параметры:
- `IP`: IP-адрес Steam Deck (по умолчанию `192.168.0.104` или `192.168.0.103`).
- `-t, --tab <название>`: Переключиться на нужную вкладку (`главная`, `фильмы`, `сериалы`, `мультфильмы`, `аниме`, `поиск`, `избранное`, `история`, `настройки`).
- `-r, --reload`: Перезагрузить страницу/плагин перед открытием.
- `-s, --screenshot <путь>`: Сделать скриншот экрана Steam Deck и сохранить его локально на ПК.

### Примеры:
- Открыть главную и сделать скриншот:
  ```bash
  ./open_projacktor.sh 192.168.0.104 -t главная -s /tmp/screen.png
  ```
- Перезагрузить плагин и открыть настройки:
  ```bash
  ./open_projacktor.sh 192.168.0.104 -r -t настройки -s /tmp/screen.png
  ```
